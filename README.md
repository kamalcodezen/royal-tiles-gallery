# Royal Tiles Gallery

## Live Site

https://royal-tiles-gallery.vercel.app

## Project Overview

Royal Tiles Gallery is a modern tile showcase website where users can explore premium tile collections, search tiles, view detailed information, and manage their profile. The platform provides a clean and responsive experience across all devices.

## Features

- User Authentication (Email/Password & Google Login)
- Browse All Tiles Collection
- Search Tiles by Title
- View Tile Details
- Protected Routes
- My Profile Page
- Update Profile Name & Image
- Responsive Design
- Custom Not Found Page
- Loading Spinner/Skeleton

## Technologies Used

- Next.js (App Router)
